# 煤炭规程智能体管理平台

一个基于 React + Vite + Ant Design 的煤炭规程智能体前端管理系统，提供对话、知识库管理、RAG检索和用量监控功能。

## 功能特性

### 1. 智能对话
- 多会话管理，支持创建、切换和删除对话
- 流式消息展示，支持 Markdown 渲染
- 历史对话记录
- 模拟 AI 回复（待接入后端 API）

### 2. 知识库管理
- 创建和管理多个知识库
- 文档上传（支持 PDF、Word、TXT）
- 文档索引状态管理
- 统计数据展示（知识库数量、文档数量、存储空间）

### 3. RAG 配置与测试
- 检索参数配置（检索方式、Top-K、相似度阈值）
- 生成参数配置（模型选择、温度、最大长度）
- 实时检索测试
- 答案生成预览
- 配置保存功能

### 4. 用量监控
- 实时统计数据（调用次数、Token使用、成本、响应时间）
- 调用趋势图表
- 功能使用分布（饼图）
- Token消耗统计（柱状图）
- 详细调用日志
- 数据筛选和导出

## 技术栈

- **框架**: React 18
- **构建工具**: Vite 5
- **UI 组件库**: Ant Design 5
- **图标**: @ant-design/icons
- **路由**: React Router v6
- **图表**: Recharts
- **Markdown渲染**: react-markdown
- **日期处理**: dayjs

## 安装运行

### 前置要求

- Node.js >= 16.0.0
- npm >= 8.0.0 或 yarn >= 1.22.0

### 安装步骤

1. **进入项目目录**

\`\`\`bash
cd coal-regulation-ai
\`\`\`

2. **安装依赖**

使用 npm:
\`\`\`bash
npm install
\`\`\`

或使用 yarn:
\`\`\`bash
yarn install
\`\`\`

3. **启动开发服务器**

使用 npm:
\`\`\`bash
npm run dev
\`\`\`

或使用 yarn:
\`\`\`bash
yarn dev
\`\`\`

4. **访问应用**

浏览器会自动打开 [http://localhost:3000](http://localhost:3000)

### 构建生产版本

\`\`\`bash
npm run build
\`\`\`

构建产物将生成在 `dist` 目录下。

### 预览生产版本

\`\`\`bash
npm run preview
\`\`\`

## 功能说明

### 对话界面

- **新建对话**: 点击左侧"新建"按钮创建新会话
- **切换对话**: 点击会话列表中的任意对话切换
- **发送消息**: 输入框输入内容，按 Enter 发送，Shift+Enter 换行
- **清空对话**: 点击右上角"清空对话"按钮
- **删除会话**: 点击会话右侧的删除图标

### 知识库管理

- **创建知识库**: 点击"创建知识库"按钮，填写名称和描述
- **上传文档**: 选择知识库后点击"上传文档"
- **查看文档**: 点击知识库操作栏的"查看文档"
- **编辑/删除**: 使用表格中的操作按钮

### RAG 配置

- **配置参数**: 左侧面板调整检索和生成参数
- **检索测试**: 输入问题后点击"开始检索"
- **生成答案**: 检索完成后点击"生成答案"
- **保存配置**: 点击"保存配置"按钮保存当前设置

### 用量监控

- **查看统计**: 顶部卡片显示关键指标
- **筛选数据**: 使用时间范围和模块筛选器
- **查看图表**: 趋势图、饼图、柱状图展示数据
- **导出数据**: 点击"导出数据"按钮（功能待实现）

## 后端集成说明

当前版本使用 Mock 数据运行，不依赖后端。要接入真实后端，需要：

1. **创建 API 服务层**
   在 `src/services/` 目录下创建 API 调用文件

2. **配置 API 基础地址**
   在 `vite.config.js` 中配置代理或在代码中设置 base URL

3. **替换 Mock 数据**
   将各页面组件中的模拟数据替换为真实 API 调用

4. **添加状态管理**
   使用 Zustand 或 Redux 管理全局状态

## 常见问题

### Q: 如何修改端口号？
A: 在 `vite.config.js` 中修改 `server.port` 配置

### Q: 如何添加新的页面？
A:
1. 在 `src/pages/` 下创建新页面组件
2. 在 `src/routes/index.jsx` 中添加路由
3. 在 `src/components/Sidebar/index.jsx` 中添加菜单项

### Q: 如何自定义主题？
A: 在 `src/main.jsx` 的 `ConfigProvider` 中配置 theme 属性
