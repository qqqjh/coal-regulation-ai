```text

```

## 5. Worker 写入点

位置：`v9_worker.py`

写入时机：

```text
MinerU/docx_adapter 切块
-> BGE-M3 生成 q_dense
-> 法规召回与重排完成
-> 写入 Milvus review_doc_chunks
-> 写入 MongoDB review_chunks
-> 进入逐块审查
```

设计边界：

- 向量入库失败不会中断审查。
- MongoDB 元数据写入失败不会中断审查。
- 失败会写入 worker 日志。
- 相同 `job_id` 再次写入前，会先删除该 job 的旧 Milvus chunks，避免重复。

## 7. 后续工作

### 已完成：历史待审相似检索接口

接口：

```text
GET /api/v9/review-similar/{job_id}/{chunk_index}?top_k=5
```

行为：

1. 从 MongoDB `review_chunks` 找到当前 chunk 的 `milvus_id`。
2. 从 Milvus 取当前 chunk 向量。
3. 在 `coal_regulation_review_doc_chunks` 中检索相似历史 chunks。
默认 filter：

```text
user_id == 当前用户 and job_id != 当前 job_id
```

后续管理员可扩展为：

```text
org_id == 当前组织
```

验证摘要：

```text
current job: similar_current_smoke
history job: similar_history_smoke
same user: smoke
vector: identical 1024-d float vector
result: hits 1 similar_history_smoke 1.0
```

验证后已清理 smoke 数据。
